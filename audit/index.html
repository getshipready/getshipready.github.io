FAQ

What access do you need?

Read access to the repo (a GitHub collaborator invite or a ZIP), and the output of our read-only SQL check from your Supabase SQL editor. We never ask for production keys or dashboard logins.

What exactly is 'agent-run'?

We run the Ship-Ready Crew on your code, then a human reviews every finding, removes false positives, and writes the summary and fix order. You get the speed of agents with a human sign-off.

Do you fix the issues?

The report includes patches and SQL you or your agent can apply. Fix-it-for-you work is quoted separately if you want it.

What if you find nothing?

Then you get a clean report you can show users or investors, and that's the point. If we find no medium-or-higher issues, we refund half.

Confidentiality?

Your code is used only for your audit and deleted 30 days after delivery. Happy to sign your NDA.
