About Ship-Ready

Ship-Ready makes pre-launch safety checks for apps built with AI tools such as Lovable, Bolt, v0, Replit, Cursor and Claude Code, usually on Next.js or Vite with Supabase, Stripe and Vercel. These tools get an app working fast. They often leave behind the same few problems: Supabase tables with Row Level Security off or open to everyone, secret keys shipped to the browser, Stripe webhooks that are never verified, and admin checks that only hide data in the UI while the API still serves it.

In 2025 a researcher scanned 1,645 apps showcased by one AI app builder and found about 10% with database rules that let anyone read or write user data (CVE-2025-48757). We build checks for exactly these problems, so you find them before your first user does.

What we offer

  • Lite (free, open source): Agent Skills for Claude Code, Cursor, Codex and Claude.ai, plus an offline quick scan that makes no network calls.
  • Crew ($39): the full toolkit, including an automated two-account test that checks one user can't read another user's rows.
  • Audit ($129 per app): an agent-run launch audit of your repo with a written report.

How we work

Our checks are rerunnable: the same code gives the same findings, with file and line, so you can run them in CI and confirm a fix. We'd rather tell you the limits of a check than oversell it.
